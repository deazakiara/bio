Uprak Biologi 3D: situs statis (HTML + gambar), tanpa database dan tanpa PHP.

Isi folder ini diunggah apa adanya ke folder root situs (di CloudPanel: htdocs/<domain-kamu>/),
sehingga index.html berada langsung di dalam folder root itu.

Tidak butuh internet ke CDN: three.js, anime.js, dan font sudah ada di folder vendor/ dan fonts/.

Sumber gambar: OpenStax Anatomy & Physiology 2e dan Biology 2e (CC BY-NC-SA 4.0),
kredit tercantum di bawah tiap gambar. Hanya untuk penggunaan non-komersial.
Font: Libre Franklin dan Source Serif 4 (SIL Open Font License). three.js dan anime.js: lisensi MIT.
